==================================================
2. TIPOS DE USUÁRIO
==================================================
 
Existem três perfis:
 
CLIENTE
- Solicita serviços
- Cadastra múltiplos endereços
- Recebe orçamentos
- Contrata prestadores
 
PRESTADOR
- Cadastra os serviços que realiza
- Cadastra sua localização
- Define sua área de atendimento
- Recebe solicitações compatíveis com sua região
 
ADMINISTRADOR
- Gerencia a plataforma
- Possui endpoints administrativos protegidos
 
Um mesmo aplicativo React Native será utilizado pelos perfis.
O backend será responsável pela autorização.
 
==================================================
3. FORMAS DE AUTENTICAÇÃO
==================================================
 
Precisamos suportar:
 
1. Email + senha
2. Google
3. Facebook
 
Para email/senha:
 
- A senha NUNCA pode ser armazenada como texto puro.
- Utilize algoritmo moderno e adequado para password hashing.
- Não implemente criptografia reversível de senha.
- Explique a estratégia utilizada para hash e salt.
- Se o algoritmo escolhido já incorporar salt automaticamente no hash,
evite armazenar informação redundante desnecessariamente.
 
Para login social:
 
- Utilize OAuth 2.0 / OpenID Connect quando aplicável.
- O backend deve validar a identidade/tokens enviados pelo provedor.
- Nunca confiar apenas no ID ou email recebido do frontend.
- Não armazenar access tokens sociais persistentemente sem necessidade.
