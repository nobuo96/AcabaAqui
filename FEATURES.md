O Cliente pode cadastar uma nova solicitação de serviço.
Deve ser informado o tipo de serviço, a área aproximada do serviço em m² e os horários disponíveis para uma visita para orçamento.
Prestadores que atendem naquela área devem receber uma notificação com o novo serviço.

O Prestador pode aceitar a solicitação. Ao fazê-lo, deve escolher um horário para a visita de orçamento presencial. O horário escolhido fica bloqueado para outros prestadores.

O cliente pode confirmar os horários das visitas agendadas. Após confirmação um chat é disponibilizado para comunicação entre cliente e prestador.

O prestador pode enviar um orçamento ao cliente. Cliente deve receber todos os orçamentos dos prestadores que o visitaram. O cliente pode aprovar um orçamento. Ao fazê-lo, uma notificação é encaminhada aos prestadores com a decisão do cliente.

O cliente deve ser capaz de realizar o pagamento pelo aplicativo via pix ou  cartão.
Após o pagamento à plataforma, a solicitação fica "aguardando aprovação" do cliente.
O fornecedor deve receber o pagamento apenas após a aprovação do cliente

Após a execução do serviço o cliente deve aprovar o serviço na plataforma. Isso irá  acionar o pagamento do prestador de serviços, que deve receber o dinheiro em sua conta.

O sistema exibe lista de serviços com status e prazos. 
Ao escolher um serviço deve-se exibir mais detalhes do serviço, seu status atual e opções para contestar serviço não executado ou liberar pagamento

O sistema atualiza status para “em disputa” e permite registrar evidências. Caso o prestador não prove que executou o serviço o dinheiro é devolvido ao cliente.

O sistema permite abrir chamado e atualiza status para “garantia acionada”. O prestador possui um prazo para corrigir o serviço. Após a correção o cliente pode finalizar a garantia acionada como resolvida.
